Module

CardGrid

Composant qui affiche une grille interactive de cartes pour voter. Inclut les valeurs: 1, 2, 3, 5, 8, 13, 20, 40, 100, ?, café

Version:
  • 1.0.0

View Source ui/components/CardGrid.js, line 1

Methods

# inner renderCards(app) → {void}

Chaque carte:

  • Possède un onclick qui appelle app.castVote(value)
  • Affiche la valeur ou un emoji (? ou ☕)
  • Possède des styles CSS personnalisés par type
  • "?" : gradient orange
  • "coffee" : gradient marron + emoji ☕
